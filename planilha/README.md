# Estrutura da planilha

O modelo inicial possui a aba `Atendimentos` com estas colunas:

1. `data_hora`
2. `telefone`
3. `nome`
4. `mensagem`
5. `origem`
6. `status`
7. `resposta`
8. `id_mensagem`

A aba `Dicionario` explica o tipo e a finalidade de cada campo. Os nomes da linha 1 devem ser preservados para o mapeamento do n8n.

Planilhas preenchidas e dados pessoais nao devem ser adicionados ao repositorio.
