# Fluxos do n8n

Os fluxos exportados em JSON serao guardados nesta pasta.

Antes de adicionar um arquivo:

1. Use apenas dados ficticios durante os testes.
2. Revise o JSON em busca de tokens, senhas, telefones e outros dados pessoais.
3. Nao exporte nem armazene credenciais nesta pasta.
4. Use nomes claros, como `01-receber-mensagem.json`.
